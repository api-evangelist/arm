# Arm

> Arm Holdings plc (NASDAQ: ARM) is the semiconductor and software design company behind the energy-efficient Arm architecture that powers most of the world's smartphones and billions of chips across mobile, automotive, IoT, edge AI, servers, and cloud. Arm licenses processor IP (Cortex, Neoverse, Ethos, Mali) and Compute Subsystems rather than manufacturing chips. Arm does not currently publish a public REST API product; this index catalogs its developer surface and web properties.

## Developer

- [Arm Developer Hub](https://developer.arm.com): Central developer platform — tools, models, learning, and documentation across AI, mobile, automotive, servers, and edge.
- [Documentation](https://developer.arm.com/documentation): Technical reference manuals, architecture and software documentation.
- [Arm Learning Paths](https://learn.arm.com): Hands-on getting-started tutorials and guided learning paths.
- [Arm Community](https://community.arm.com): Developer forums, support, and knowledge base.
